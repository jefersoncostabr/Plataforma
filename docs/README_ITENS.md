# Como criar itens (JSON)

Veja o arquivo `docs/como_criar_itens.md` para um guia completo sobre como adicionar novos itens ao jogo usando o sistema de arquivos JSON.

## Resumo rápido
- Crie um arquivo em `config/items/` (ex: `cinto.json`)
- Preencha os campos obrigatórios: `id`, `nome`, `spriteColetavel`, `zIndex`, `efeitos`
- Veja exemplos e detalhes no guia citado acima
