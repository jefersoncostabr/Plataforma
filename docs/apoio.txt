# Apoio rapido - comandos do dia a dia

> Em 10 segundos: aqui ficam os comandos git + debug que a gente vive esquecendo. Copie e cole.

## Git - voltar no tempo (CUIDADO: apaga mudanca local!)
- Voltar pro ultimo commit (descarta tudo local!):
  `git reset --hard HEAD`
- Voltar pra um commit especifico (exemplo):
  `git reset --hard 8c4e92`
- Ver historico curto:
  `git log --oneline`
- Ver historico da branch atual:
  `git log --oneline --decorate --no-merges`

## Git - levar pra main (merge)
  `git checkout main`
  `git pull origin main`
  `git merge <branch>`
  `git add .`
  `git commit`
  `git push origin main`

## No console do navegador (F12)
- Mostra velocidade do player:
  `window.toggleDebugVelocidadePlayer()`
- Limpa save da base (so dev):
  `window.apagarBasePersistidaDev()`

## Testar gamepad (sem controle fisico)
  `gp.mostrarEstadoGamepad()`   (botoes ao vivo)
  `gp.mostrarMapeamentos()`     (acao -> botao)
  `gp.simularAcao('pulo')`      (finge que pulou)
  `gp.mostrarAcoesAtivas()`     (o que esta ativo agora)
  `gp.testarConectividade()`
- Site util: https://gamepad-tester.com/

## Diversos
- Ver quem e voce no git:
  `git config --get user.email; git config --get user.name`
- Subir servidor do editor:
  `node tools/editor/editor-save-server.js`
