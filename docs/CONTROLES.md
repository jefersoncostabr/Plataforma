# Guia de Controles

## Jogador (Armadura)
| Ação | Comando | Observação |
| :--- | :--- | :--- |
| **Movimento** | `A`, `D` / `Setas` | Mover personagem |
| **Pulo / Salto** | `Espaço` | Toque duplo no ar para Salto |
| **Agachar** | `S` / `Seta ↓` | Necessário para interagir |
| **Atacar (Chute)** | `K` | Combate corpo a corpo |
| **Atirar** | `I` | Requer Arma e Munição |
| **Lançar Garra** | `J` | Requer item Garra |
| **Cinto (Item)** | `L` | Muda item ativo |
| **Alternar Equip** | `E` | Alterna entre Arma e Escudo |
| **Mochila** | `Enter` | Abre o inventário |
| **Interagir** | `E` | Agachado = Menu de Crafting |
| **AirDrop** | `U` ou `W+I` | Chama suprimentos |
| **Ejetar BB** | `Y` | Abre/Fecha armadura (Ejeta o BB) |
| **Troca de Pet** | `Q` | Alternar entre pets aliados |
| **Carregamento** | `T` | Ativa eletricidade temporária |

## Aliados (Cão e Gato)
*Para assumir o controle: Agache-se e encoste no pet, então pressione `Q`.*

| Ação | Comando | Efeito Específico |
| :--- | :--- | :--- |
| **Movimento** | `A`, `D` / `Setas` | Mover pet aliado |
| **Pulo** | `Espaço` | Salto do pet |
| **Habilidade** | `K`, `V`, `X` | **Cão**: Morder / **Gato**: Arrastar |
| **Soltar** | `K`, `V`, `X` | Pressione novamente para soltar |
| **Sair** | `Q` | Retorna ao Player (2x rápido) |

## Controle do Bebê (BB)
*O BB é controlado após ejetar da armadura com `Y`.*

| Ação | Comando | Função |
| :--- | :--- | :--- |
| **Movimento** | `A`, `D` / `Setas` | Mover bebê |
| **Pulo** | `Espaço` | Salto baixo |
| **Interagir** | `E` | Alavancas, Resgate ou Entrar no Casco |
| **Assumir Pet** | `Q` | Troca para controle do aliado |
| **Fechar Casco** | `Y` | Fecha a armadura à distância |

## Atalhos de Debug (Testes)
*Teclas numéricas e comandos para facilitar a depuração.*

| Tecla | Comando | Função |
| :--- | :--- | :--- |
| `0` | Reset Total | Limpa todo o progresso e inventário |
| `2` | Limpar Base | Reseta equipamentos e estado da armadura |
| `3` | +10 XP | Ganha experiência instantaneamente |
| `4` | Próx. Nível | Pula para a próxima fase do jogo |
| `6` | Skills | Abre ou Fecha o menu de habilidades |
| `7` | Reset Skills | Zera a árvore de habilidades e pontos |
| `8` | Jump Debug | Força pulo dos inimigos (IA) |
| `9` | Kill All | Elimina todos os inimigos da tela |
| `G` | Grade | Ativa/Desativa Grade de Debug |
